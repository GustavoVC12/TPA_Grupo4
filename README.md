# TPA_Grupo4

### Como usar o sistema:
1 - Execute o arquivo main e selecione o tipo de lista a ser criado.

2 - Gere um arquivo com os contatos (opção 9). Deve ser especificado
o número de contatos desejado.

3 - Após a geração dos contatos, carregue os contatos na lista
(opção 1).


Não é necessário exluir o arquivo de contatos caso deseje trocar.
Basta gerar e carregar os dados novamente através do menu.
